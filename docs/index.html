核心原则

安全、透明、可逆

每个 skill 都是 markdown + 可能跑代码。Mantle 让你装之前先看清楚，用之中随时关停。

Safe by default

装新 skill 前先跑审查：红黄绿三色风险等级 + Trust Score，确认行为后再启用。

Transparent

一键查看完整 SKILL.md、全部脚本文件、文件树与行为画像。哪行代码触发了警告，看得清清楚楚。

Reversible

「禁用」≠ 删除：只把目录改名 .disabled，一键复活。删除前还有二次确认。

功能

管理技能，该有的都有

三栏布局：来源 / 技能列表 / 详情·审查。Glass（macOS 通透）设计语言。

风险审查 + Trust Score

扫描脚本里的命令执行 / 网络 / 文件写入等敏感调用，按红黄绿分级并给出 0–100 信任分。

文件全透明

详情面板「概览 / 文件」双 tab，文件树 + 内容预览。skill 里到底装了什么，一目了然。

启用 / 禁用 / 移动

开关一键启停；在「全局 ↔ 项目」之间移动技能；删除前二次确认，绝不误删。

内置技能市场

从官方 anthropics/skills 与社区市场实时拉取技能，看详情、一键安装到任意来源。

自动更新

基于 minisign 签名的自动更新：设置里点「检查更新」，下载、安装、重启一气呵成。

全局 + 项目级

同时管理全局 ~/.claude/skills 与任意项目的 .claude/skills，来源持久化。
